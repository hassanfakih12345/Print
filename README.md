# طباعة الفواتير — POS

واجهة ويب بسيطة لتعبئة الفاتورة (معلومات المحل، اللوغو، الزبون، المنتجات) وطباعتها على طابعة POS حرارية (58 أو 80 مم).

## التشغيل
ما في شي لازم تنزّلو. افتح `index.html` بمتصفح Chrome أو Edge.

## إعداد الطابعة (مرة وحدة)
1. نزّل درايفر الطابعة (Xprinter, Epson, ...) وتأكد إنها ظاهرة بالويندوز كطابعة عادية.
2. بالبرنامج اختار عرض الورق (80 أو 58 مم) من "إعدادات الطباعة".
3. اضغط **طباعة** (أو Ctrl+P)، واختار الطابعة الحرارية، ومن "More settings":
   - Margins: **None**
   - Scale: **Default / 100**
   - شيل علامة **Headers and footers**

## المميزات
- لوغو المحل (بيتحول أبيض وأسود تلقائياً للطابعة الحرارية)
- رقم فاتورة بيزيد تلقائياً
- المنتجات بتنحفظ مع أسعارها وبتطلع اقتراحات
- خصم (مبلغ أو نسبة)، ضريبة، المدفوع والباقي
- عملة ثانية مع سعر صرف (مثلاً دولار ← ليرة)
- كل الإعدادات بتنحفظ بالمتصفح
